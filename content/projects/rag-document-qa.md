# RAG-Powered Document Q&A Platform

Built a retrieval-augmented generation system that lets enterprise users query internal documentation using natural language.

## Role

Tech lead — architecture, backend, and LLM integration

## Stack

Python, FastAPI, PostgreSQL, OpenAI embeddings, Pinecone, React

## Highlights

- Designed chunking and retrieval pipeline achieving 92% answer relevance in internal evals
- Reduced average query latency from 8s to 1.2s via caching and async retrieval
- Shipped admin dashboard for content ingestion and eval monitoring

## Impact

Adopted by 3 internal teams; ~10k queries/month at peak
